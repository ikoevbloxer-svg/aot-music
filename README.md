# AoT Music (Fabric 1.20.1)

Саундтреки Attack on Titan для сервера и клиента.

- **Фон**: 4 трека по очереди. Между треками пауза 10–20 минут, как у ванильной музыки. Один и тот же трек подряд не повторяется. Все игроки слышат одно и то же одновременно.
- **Команды (только операторы, уровень 2)**:
  - `/aotmusic play <трек>` — включить командный трек для всех сразу
  - `/aotmusic list` — список командных треков
  - `/aotmusic stop` — остановить; фон вернётся по обычному расписанию
- Название трека показывается справа сверху на 5 секунд, когда трек начинается.
- Пока мод активен, ванильная музыка выключена.

## Сборка
Через GitHub Actions (Java 17) или локально: `./gradlew build`, готовый jar в `build/libs/`.

## Ограничения
- Кто зашёл посреди трека, его не услышит до следующего: мы не перематываем трек для новичков.
- Треки из AoT защищены авторским правом. Для личного использования это ок, для публикации — нет.
